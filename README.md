# 테니스판타지 월 수강료 계산기

> 배포판 2026-08-31 · 가격표 기준: 반포점 2026-07-06 / 방배점 2024-03-16 (운영자 확인 완료)
>
> `prices.js`는 Notion 가격표(반포·방배)를 그대로 옮긴 실제 금액입니다.
> `holidays.js`의 2026·2027년 공휴일은 아직 관보와 전수 대조하지 않았으니, 매달 계산 전에 화면의 **`이 달의 휴일 후보`** 목록이 실제 달력과 맞는지 눈으로 확인해 주세요.

해당 월의 휴일 후보 중 사용자가 직접 선택한 날짜만 반영해 월 수강료를 계산하는 내부 도구입니다. 선택한 일반 공휴일은 수업 횟수에서 제외하고, 선택한 대체공휴일과 임시공휴일은 정상 수업 횟수에 포함해 계산 근거로 남깁니다. 인터넷, 설치, 서버 없이 사용할 수 있습니다.

## 계산기 열기

1. 이 폴더의 `index.html`을 더블클릭합니다.
2. 계산할 달을 확인합니다.
3. 지점, 가격 상품, 주당 횟수, 수업 요일을 차례로 선택합니다.
4. `반영할 휴일`에서 이번 계산에 적용할 휴일을 직접 선택합니다. 처음에는 아무 휴일도 선택되어 있지 않습니다.
5. 달력에서 수업일·선택 휴일·휴강·보강을 확인합니다.
6. 필요하면 적용 요금이나 최종 결제액을 수정합니다. 숫자는 입력 후 Enter를 누르거나 입력칸 밖을 클릭해야 확정됩니다.
7. `계산 내역 복사` 또는 `회원 안내 문구 복사`를 사용합니다.

초기 화면에 큰 0원이 보이지 않는 것이 정상입니다. 필수 조건이 모두 정해진 뒤에만 금액이 표시됩니다.

## 계산 정책

- 대상 기간은 선택한 달의 1일부터 말일까지입니다.
- 휴일은 자동으로 적용하지 않습니다. 월을 선택하면 후보만 표시되며, 사용자가 선택한 휴일만 계산에 전달됩니다.
- 선택한 일반 공휴일(`regular`)은 예정 수업일과 겹치면 제외합니다. 미선택 일반 공휴일은 정상 수업일로 계산합니다.
- 선택한 대체공휴일(`substitute`)과 임시공휴일(`temporary`)은 제외하지 않고 정상 수업에 포함하며 안내 근거에 표시합니다.
- 일요일은 자동으로 제외하지 않습니다. 선택한 수업 요일이면 정상 수업일입니다.
- 5주차가 있어 기준 횟수를 초과해도 횟수를 자르지 않습니다.
- `추가 제외`는 지점 휴무나 개별 휴강에 사용합니다.
- `추가 포함`은 일반 공휴일 수업 복구 또는 정규 요일 밖 보강에 사용합니다.
- 1:2·그룹 가격은 1인 기준입니다. 인원수를 곱하지 않습니다.

## 가격표 수정하기

운영 전 Notion의 `테니스판타지 반포점 가격표`와 `테니스판타지 방배점 가격표` 원문을 확보한 뒤 `prices.js`를 수정합니다.

1. 메모장이나 코드 편집기로 `prices.js`를 엽니다.
2. `source`를 실제 자료명으로, `updatedAt`을 수정일로 바꿉니다.
3. 지점별 `sourceTitle`과 `effectiveFrom`을 가격표 원문과 시행일로 바꿉니다.
4. 각 상품의 `label`을 가격표 한 행을 정확히 구분하는 이름으로 바꿉니다.
5. `pricingModel`을 원문 금액 단위에 맞춰 지정합니다.
6. `monthlyFees`의 `"1"`, `"2"`, `"3"`에 실제 양의 정수 금액을 입력합니다. 지원하지 않는 횟수는 `0`을 넣지 말고 키를 삭제합니다.
7. 요일 제한이 있으면 `allowedWeekdays`를 수정합니다. `0=일요일`, `1=월요일`, …, `6=토요일`입니다. 전 요일 허용 상품은 이 줄을 생략해도 됩니다.
8. 저장한 뒤 `tests.html`을 열어 자동 테스트가 모두 통과하는지 확인합니다.
9. `index.html`에서 반포점과 방배점의 모든 상품·횟수 조합을 원문과 한 행씩 교차 확인합니다.

가격 모델의 의미는 다음과 같습니다.

- `monthly4week`: 4주 기준 월 요금. 기준 횟수와 다르면 회당 금액으로 증감합니다.
- `perSession`: 한 회 가격. 적용 요금 자체를 회당 금액으로 사용합니다.
- `flatMonthly`: 실제 횟수와 무관한 고정 월정액입니다.

가격이 바뀌면 해당 상품의 `monthlyFees` 숫자만 고치고, 지점의 `effectiveFrom`을 새 시행일로 바꾸세요.

### 라커·라켓 대여비

`prices.js` 맨 위의 `rentals` 항목에서 관리합니다.

```js
rentals: [
  { id: "locker", label: "라커 대여", monthlyFee: 10000 },
  { id: "racket", label: "라켓 대여", monthlyFee: 10000 }
]
```

대여비는 **월 정액**이라 수업 횟수와 무관합니다. 공휴일이나 휴강으로 수업이 줄어도 깎이지 않고, 수강료 계산이 끝난 뒤 더해집니다. 항목을 추가하려면 같은 형식으로 한 줄 더 쓰면 됩니다.

## 공휴일 수정하기

`holidays.js`는 연도별 날짜, 이름, 유형을 갖습니다.

```js
{ date: "2027-01-01", name: "신정", kind: "regular" }
```

1. 정부 관보의 해당 연도 월력요항을 기준으로 모든 일반 공휴일을 전수 대조합니다.
2. 빠진 날짜는 해당 연도 배열에 추가하고 날짜순으로 정렬합니다.
3. 유형을 정확히 지정합니다.
   - `regular`: 사용자가 선택하면 수업 횟수에서 제외
   - `substitute`: 사용자가 선택하면 정상 수업에 포함하고 안내 표시
   - `temporary`: 사용자가 선택하면 정상 수업에 포함하고 안내 표시
4. 같은 날짜를 두 번 넣지 않습니다.
5. 매주 일요일을 공휴일로 반복 입력하지 않습니다.
6. 현재 연도와 다음 연도 배열을 항상 유지합니다.
7. 저장 후 `tests.html` 자동 테스트와 `index.html`의 `반영할 휴일`, `이 달의 휴일 후보`를 확인합니다.

현재 파일의 2026년 자료는 한국천문연구원의 2026년 월력요항 안내를 기초로 작성했지만 운영 검수를 대신하지 않습니다. 2027년 대체·임시공휴일은 이 버전에서 의도적으로 넣지 않았습니다. 정부 관보 원문 확인 후 추가하세요.

## 자동 테스트 실행하기

1. `tests.html`을 더블클릭합니다.
2. 화면 위쪽에 `실패 0`과 `모두 통과`가 표시되는지 확인합니다.
3. 실패가 있으면 아래 표의 `기대값`과 `실제값`을 확인합니다.
4. 가격이나 공휴일 데이터를 바꾼 뒤에도 항상 다시 실행합니다.

자동 테스트는 운영 가격·공휴일 파일을 읽지 않고 합성 데이터로 계산 공식만 검증합니다. 따라서 테스트 통과만으로 운영 데이터가 정확하다는 뜻은 아닙니다.

## 자주 보이는 오류

- `prices.js를 불러오지 못했습니다.`: 여섯 제품 파일이 같은 폴더에 있는지, 파일명이 정확한지 확인합니다.
- `가격표 형식이 올바르지 않습니다`: 오류에 표시된 지점·상품·필드 주변의 쉼표, 따옴표, 금액을 확인합니다.
- `holidays.js를 불러오지 못했습니다.`: 파일명과 위치를 확인합니다.
- `공휴일 데이터 형식이 올바르지 않습니다`: 날짜 형식, 연도, 중복 날짜, `kind` 철자를 확인합니다.
- `calc.js를 불러오지 못했습니다.`: `calc.js`가 같은 폴더에 있는지 확인합니다.
- `공휴일 데이터가 없습니다`: 해당 연도를 `holidays.js`에 추가하는 것이 우선입니다. 긴급 확인용으로만 `공휴일 없이 계산`을 선택할 수 있으며, 그 결과에는 경고가 붙습니다.
- `요일 N개를 선택해야 합니다`: 선택한 주당 횟수와 같은 수의 요일을 선택합니다.
- `가격 정보가 없습니다`: 해당 상품의 `monthlyFees`에 선택 횟수 키가 있는지 확인합니다.
- 복사가 되지 않을 때: 화면에 나타난 직접 복사용 텍스트를 선택해 복사합니다.

## 다음 회원 계산

`다음 회원 계산`은 회원명, 조정 사유, 적용 요금 조정, 최종 결제액 조정만 비웁니다. 월·지점·상품·횟수·요일·선택한 휴일·추가 휴강·보강은 유지하므로 같은 반의 여러 회원을 이어서 계산할 수 있습니다.

## 대여 항목

입력 패널 `11. 대여 항목`에서 라커·라켓 대여를 체크하면 최종 금액에 월 정액으로 더해집니다. 기본값은 둘 다 해제이며, `다음 회원 계산`을 누르면 선택이 풀립니다.

수업 횟수가 줄어도 대여비는 그대로입니다. 계산 내역과 회원 안내 문구에도 항목별로 표시됩니다.

### 알아두실 제약

- **평일+주말 혼합 상품**(예: 평일 2회 + 주말 1회)은 요일 구성을 계산기가 강제하지 않습니다. 요일을 직접 맞춰 주세요.
- 쿠폰레슨(1·5·10회), 코트 대여, 볼머신 대여는 월 정액이 아니라 이 계산기에 없습니다.
- 1:2·그룹 금액은 모두 **1인 기준**입니다. 인원수를 곱하지 마세요.

이 도구는 회원명과 조정 사유를 브라우저 저장소에 저장하거나 외부로 전송하지 않습니다. 페이지를 새로고침하면 입력 상태는 사라집니다.
